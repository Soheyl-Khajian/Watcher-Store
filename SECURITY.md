# Security

## Reporting a problem

Please report security problems privately, through GitHub's
[private vulnerability reporting](https://github.com/Soheyl-Khajian/Watcher-Store/security/advisories/new)
for this repository, not in a public issue. Include what you found, how to
reproduce it, and what an attacker could do with it.

You should hear back within a week. Once the problem is understood, it is
fixed on `master` and the report is published as an advisory, crediting
you unless you would rather not be named.

## Supported versions

Only the latest release, and `master`, receive fixes.

## Scope

This is a portfolio project, not a running shop: there is no production
deployment, and the demo data, accounts and payments are not real. Reports
about the code are welcome; please do not test against anyone else's
deployment of it.

How the project protects sessions, payments, the database and the
containers is described under
[Security and engineering decisions](README.md#security-and-engineering-decisions)
in the README.
